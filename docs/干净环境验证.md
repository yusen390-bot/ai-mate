# 干净环境验证清单

前提：Windows/macOS/Linux + Node.js **24+** + Git。无需 Python、无需 C++ 编译工具链。

## 步骤

```powershell
# 1. 克隆
git clone https://github.com/yusen390-bot/ai-mate.git
cd ai-mate

# 2. 安装依赖（root + server + client）
npm run setup

# 3. 环境变量
Copy-Item .env.example .env
# 编辑 .env：MODEL_BASE_URL / MODEL_API_KEY / MODEL_NAME

# 4. 自动化测试（服务端，使用内存数据库）
npm test

# 5. 类型检查 + 前端构建
npm run typecheck
npm run build

# 6. 数据库自检（四表 + 事务 + 级联 + 迁移版本）
npm run db:test

# 7. 启动
npm run dev
```

## 冒烟检查

- [ ] http://localhost:5173 打开，顶部显示「后端在线」「模型已配置」
- [ ] `GET /health` 返回 `status: "ok"`、`db.schemaVersion: 3`
- [ ] 新建项目 → 「用 AI 生成计划」→ 保存 → 确认 → 自动执行 → 项目 `done`
- [ ] 给某任务勾「需人工审批」→ 执行时暂停 → 「批准并继续」→ 完成
- [ ] 重启后端 → 项目状态 / 任务 / 执行记录仍在

## 常见问题

| 现象 | 处理 |
|---|---|
| `npm` 提示"禁止运行脚本" | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，重开终端 |
| 模型返回 502 | 检查 `.env` 的 `MODEL_BASE_URL` / `MODEL_API_KEY`，以及网络/代理 |
| 端口被占用 | 关掉旧的服务窗口；或改 `.env` 的 `PORT` 与 `client/vite.config.ts` 端口 |
| 手机访问不了 | 同一 Wi-Fi + Windows 防火墙放行 5173/3001（见 README）|
